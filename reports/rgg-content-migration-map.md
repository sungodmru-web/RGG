## Concrete implementation conflicts
1. **Route/metadata mismatch:** App and `src/lib/pageMetadata.ts:11-87` only define legacy routes; no new metadata for `/publications`, `/technical-assistance`, `/endorsements`; no redirects. French metadata is duplicated in `App.tsx:181-257` and also lacks new routes.
2. **Build/SEO mismatch:** `vite.config.ts:107-150` prerenders/sitemaps every `ROUTE_METADATA` route and publication URLs under `/research/:slug`; must be changed to new canonical paths and exclude legacy pages/redirects from indexable content. `robots.txt` exists but no sitemap source route is currently shown in app.
3. **Publication data mismatch:** API/schema uses publication terminology and current UI only filters publication type; no theme/category browser, A–Z filtering, clear combined theme/letter/search behavior, or publication-type secondary filter as specified. `RESEARCH_PUBLICATIONS` is empty fallback. Current hard-coded topics are not derived from data (`Research.tsx:86-93`).
4. **Admin links conflict:** `src/components/admin/AdminLayout.tsx:79`, `AdminGuard.tsx:142`, and publication cards/forms point to `/research`; update to `/publications` while preserving Clerk-only auth and existing admin routes/security.
5. **No endorsement data architecture:** `lib/db/src/schema` has publications/admin rate limits but no endorsement model; no public/admin endorsement routes. Spec requires approved-only display and draft/approved/archived preparation.
6. **Header/footer conflict:** legacy Research/About/Contact labels and URLs remain (`SiteHeader.tsx:9-15`, `SiteFooter.tsx:20-51,157`), contrary to five-item primary nav and concise legal footer.
7. **Internal-link conflicts:** extensive `/framework`, `/economy`, `/research`, `/contact`, `/formats`, `/policymakers` links in `Book.tsx`, `Framework.tsx`, Consultancy, Authors, Media, Partnerships and footer will break or bypass consolidation unless updated/redirected.
8. **Test conflicts:** only framework, metadata, layout/admin, publication-form/page tests plus book visual/mobile tests are present; `pageMetadata.test.ts:52-56` explicitly expects `/research` metadata/canonical. No route/redirect, new-route, endorsement, bilingual parity, A–Z/theme, or responsive homepage horizontal tests. Existing declared baseline (spec lines 964-983) is 30 website, 67 API, 3 book, but repository does not contain a route acceptance suite proving those counts.
9. **Legacy fake data conflict:** `src/pages/LegacyHome.tsx:33` defines `JOURNAL_ARTICLES`; specification explicitly says remove/do not migrate it. It is currently not routed by App, but must not be reintroduced.
10. **Horizontal homepage not implemented:** current `Home.tsx` is the old homepage; no evidence of required six-panel controlled CSS scroll-snap, arrow buttons, keyboard handling or progress controls. Must avoid document-level overflow and preserve 3D-book mobile gesture tests.
11. **Potential performance conflict:** many legacy pages use eager cinematic background images; consolidation should not preload 3D book from homepage and should preserve lazy book behavior.
12. **Bilingual parity:** existing pages generally use `useLanguage().text`, but new route labels/metadata/redirect destinations and endorsement empty state must be added in both English/French; protected book title should remain consistent (do not blindly translate it).

## Unsafe content triage summary
- **Remove from public migration pending approval:** all Economy numerical stats, trade/value-chain percentages, production costs/export prices and competitive-position claims (`ECO-001..004`); they are visibly rendered despite `noReliance` notes and are editorial-review/verification-required.
- **Qualify or avoid institutional credential claims:** both author bios (`BIO-001/002`) are verification-required; retain only approved existing concise text with provenance treatment, no invented qualifications.
- **Never publish as facts:** prospective partnerships, clients, affiliations, endorsements, testimonials, institutional logos, media coverage, publication dates/prices/ISBN/publisher/purchase links, or LegacyHome journal articles.
- **No explicit Mauritius references** are present in the current routed `src/pages` content found; do not import such references from attached mockups/source assets.

The authorized destination map is therefore: `/framework` + `/formats` + `/about` → `/book`; `/research` + verified `/research/:slug` → `/publications` (+ new detail path); `/consultancy` + `/policymakers` + `/economy` + `/partnerships` + `/contact` → `/technical-assistance` (with economy unsafe facts withheld); `/authors` retained; `/media` folded into publications/contact or redirected; `/endorsements` newly created empty state; legal routes retained; all old public routes should redirect rather than remain full indexable pages.
