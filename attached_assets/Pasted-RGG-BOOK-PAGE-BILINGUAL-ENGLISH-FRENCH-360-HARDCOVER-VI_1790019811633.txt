RGG BOOK PAGE — BILINGUAL ENGLISH / FRENCH 360° HARDCOVER VIEWER

Proceed with implementation now.

OBJECTIVE

Upgrade the EXISTING interactive 3D hardcover book viewer on the RGG Book
page so visitors can switch between the official English and French hardcover
artwork while using the SAME 360° interactive book.

The experience should be:

HARDCOVER EDITION

[ ENGLISH ]   [ FRANÇAIS ]

                3D BOOK
                   ↻
          Drag to rotate 360°

The visitor must be able to switch cover language at any rotation angle.

DO NOT rebuild the Book page from scratch.

DO NOT create two separate 3D viewers.

Use ONE physical 3D book model and dynamically switch its artwork/textures.
