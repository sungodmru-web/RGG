RGG WEBSITE SIMPLIFICATION — INFORMATION ARCHITECTURE + HORIZONTAL EXPERIENCE

OBJECTIVE

Simplify the Reclaiming the Green Gold public website.

The current site contains too many public pages and too much vertical scrolling.

The new experience should feel:

- concise
- institutional
- premium
- editorial
- easy to navigate
- less bulky
- less repetitive
- easier to explore on mobile

Do NOT remove important information.

- Wouter as the router
- Clerk as the ONLY authentication provider
- PostgreSQL/Drizzle
- English/French public-site parity
- existing publication security
- existing 3D book functionality
- existing welcome gate behavior
- existing approved visual identity
- no explicit Mauritius references in public website copy

Do NOT create a second auth system.
