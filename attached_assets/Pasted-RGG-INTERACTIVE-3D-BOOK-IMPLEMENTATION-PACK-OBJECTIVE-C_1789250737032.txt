RGG INTERACTIVE 3D BOOK — IMPLEMENTATION PACK

OBJECTIVE

Create a real interactive 360° 3D hardcover book viewer for:

RECLAIMING THE GREEN GOLD / RÉCONQUÉRIR L’OR VERT

Use the exact uploaded full-wrap cover artwork as the visual source.

The viewer must allow visitors to:

- drag horizontally with mouse
- swipe/drag with finger on mobile
- rotate the book through a full 360°
- see the front cover
- see the spine
- see the back cover
- see realistic page edges
- see realistic hardcover thickness
- allow slow idle auto-rotation
- pause auto-rotation during user interaction

This must be a REAL interactive WebGL model, not a video, GIF, sprite animation, or fake 2D perspective effect.

4. TEXTURE PREPARATION
==================================================

Do NOT map the entire wrap onto one cube face.

The wrap must be split/cropped into:

BACK COVER
SPINE
FRONT COVER

Use the artwork geometry itself.

The source print dimensions shown are:

TOTAL WIDTH WITH BLEED:
444 mm

TOTAL HEIGHT WITH BLEED:
257 mm

BLEED:
3 mm

Do not guess panel dimensions blindly.

Inspect the visible trim guides / artwork geometry.

Create a helper that crops the original image into textures for:

front
back
spine

The final textures should exclude external printer marks and unnecessary bleed.

If exact crop coordinates cannot be derived safely from the source image:
implement configurable crop constants in one clearly documented file.

Example:

src/components/book/bookTextureConfig.ts

with:

front: { x, y, width, height }
back: { x, y, width, height }
spine: { x, y, width, height }

Report the crop values used.

==================================================
5. BOOK GEOMETRY
==================================================

The 3D model should represent a premium hardcover book.

Use approximate proportions based on the actual cover dimensions.

Target visual proportions:

height:
1.0

cover width:
approximately 0.68–0.72 relative to height

spine thickness:
approximately 0.07–0.10 relative to book width

Use the actual wrap geometry where possible.

Book parts:

1. front hardcover board
2. rear hardcover board
3. spine
4. page block
5. slight board overhang beyond page block

Do not create an unrealistically thick book.

==================================================
6. FRONT COVER
==================================================

Map the front-cover crop to the outside front board.

Preserve aspect ratio.

Do not distort the typography.

Do not mirror the texture.

Use proper color-space configuration so the printed colors remain accurate.

==================================================
7. BACK COVER
==================================================

Map the back-cover crop to the outside rear board.

Important:

When the visitor rotates the model to view the back, the back-cover text must read normally.

Do not accidentally mirror it.

==================================================
8. SPINE
==================================================

Map the actual spine artwork to the spine geometry.

Spine text must remain upright and readable in the expected physical orientation.

Do not replace the spine with plain green.

==================================================
9. PAGE BLOCK
==================================================

Create realistic page edges.

Color:

warm ivory / natural paper

Not pure white.

Add subtle visual page-line texture using shader/material or very lightweight procedural treatment.

Do not add thousands of page meshes.

Performance matters.

==================================================
10. HARDCOVER MATERIAL
==================================================

The cover should feel like a physical hardcover.

Use a restrained material:

roughness around 0.65–0.8

very low metallic value

slight specular response

Do not make the book look like polished plastic.

The printed gold artwork itself should appear luminous through lighting but should not behave like a mirror.

==================================================
11. LIGHTING
==================================================

Create premium studio lighting.

Use:

soft key light
subtle fill light
gentle warm rim light

Dark / deep charcoal environment.

Keep lighting aligned with RGG visual identity:

black
deep emerald
muted gold
ivory

Do not use bright neon effects.

==================================================
12. FLOOR + SHADOW
==================================================

Add a subtle ground plane or contact shadow.

The book should feel physically grounded rather than floating.

Use soft shadow only.

No giant glow.

==================================================
13. INITIAL CAMERA
==================================================

Initial view:

front cover visible
slightly turned 10–18 degrees
slightly elevated camera
book centered

The viewer should immediately recognize the physical book.

Do not start with the spine or back.

==================================================
14. INTERACTION
==================================================

Horizontal pointer movement rotates the book.

Desktop:
click + drag

Mobile:
touch + drag

Do not require users to drag vertically.

Avoid hijacking normal page scroll.

Use pointer events carefully.

Provide a secondary accessible control:

Rotate Left
Rotate Right

Buttons can appear below the canvas on mobile/accessibility layouts.

==================================================
15. FULL 360 ROTATION
==================================================

Rotation must not be clamped to a small range.

Allow continuous rotation:

0°
→ 90° spine
→ 180° back
→ 270° opposite edge
→ 360° front

Rotation should feel smooth.

Use damping/inertia but keep it restrained.

==================================================
16. IDLE AUTO ROTATION
==================================================

If user has not interacted for approximately 3 seconds:

begin very slow rotation.

Example:

roughly 6–10 degrees per second maximum.

When user interacts:

stop auto rotation immediately.

After a few seconds of inactivity:
resume gently.

Respect:

prefers-reduced-motion

If reduced motion is enabled:
disable auto rotation.

On touch devices:

Swipe to explore 360°

Use muted gold/ivory styling.

Do not obscure the book.
