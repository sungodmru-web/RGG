---
name: Admin media visibility
description: Privacy rule for direct-to-storage uploads used by the RGG publishing portal.
---

Uploaded media must remain administrator-only until it is attached to published publication content or an approved endorsement. Never serve unregistered storage objects through a public route.

**Why:** The portal uses direct-to-storage uploads followed by server registration. A failed or rejected registration can leave an orphan object, and draft editorial assets must not become public merely because an upload completed.

**How to apply:** Any new media type or content workflow must preserve private-by-default access, validate registration from trusted storage metadata, and derive public visibility from an approved content relationship.
